# E Green Solution — live SEO diagnosis

**Audit date:** 12 November 2026  
**Property checked:** sc-domain:egreensolution.in  
**Search data:** 10 August–9 November 2026 (latest data available in this check)  
**Scope:** Search Console performance and URL inspection, live redirects and page metadata, robots and sitemap, internal links, schema, public local listings, and a small content comparison.

## Executive summary

The site is receiving impressions: Google Search Console reports **2,700 impressions and 43 clicks** in the 92-day window, with **1.59% CTR** and **average position 29.8**. The main problem is that the pages are usually too far down the results for commercial Pune searches to earn clicks. “Solar installation in Pune” averaged position 53.2; “solar panel installation in Pune” 50.0; “solar installation company in Pune” 60.1; and “best solar company in Pune” 81.8. These queries had no clicks in the returned query data.

There is also a confirmed canonicalization problem still live. The code requests a permanent apex-to-www redirect, but the production apex domain currently returns **HTTP 307**. Search Console still has both apex and www pages indexed, and for the Pune landing page Google last selected the apex URL as canonical. Until the live redirect and Google-selected canonicals agree, ranking and reporting signals remain split.

The crawl did **not** find a sitewide crawl block: robots.txt permits crawling, the current sitemap is valid, and a 42-page crawl found no broken internal links or orphan pages. The priority is to consolidate the URLs, improve the relevance and proof on a small set of commercial landing pages, and strengthen Pune local prominence. This audit does not promise a #1 position; local results vary by the searcher’s location.

Search Console lists it with zero reported errors and warnings. Support these with dated Pune case studies, real project photos, system sizes, before/after bills or generation data where available, named credentials, and clear warranty terms. Avoid adding more generic paragraphs or city-name variations. |
| **P2** | Review subsidy and savings promises for accuracy | Publicly crawled homepage copy includes a guarantee of PM Surya Ghar subsidy disbursement. The scheme amount can be up to ₹78,000 for eligible residential installations, but the consumer application, technical compliance, and DISCOM/portal process determine whether CFA is released. Phrase the offer as assistance with eligible applications unless the company has a specific contractual guarantee it can honor. Link subsidy explanations to current official guidance. |
| **P3** | 37 pages still carry meta-keywords tags | The homepage’s tag contains a long list of keyword variants. Google says the meta-keywords tag has no effect on indexing or ranking. Removing these tags is cleanup, not a ranking fix. |
| **P3** | Minor structured-data and markup cleanup | Homepage JSON-LD parsed with no errors; the recognized LocalBusiness, Organization, BreadcrumbList, and FAQPage blocks passed required-field checks. Recommended LocalBusiness opening hours and Organization sameAs links are missing. The repository also has 21 repeated class attributes in HTML elements; check these for unintended style loss. None of these checks showed a sitewide indexing blocker. |

## What passed, and what remains unverified

- robots.txt returned 200, allowed the site root, and blocked only /admin/ and /solar-hero.html.
- The current sitemap is well-formed, has 39 www URLs, and no cross-host entries. All entries lack lastmod; this is optional and is not being treated as a blocker.
- The internal crawl fetched 42 URLs with no broken links or orphan pages. Most HTML pages were one or two clicks from the homepage.
- The homepage, services page, and Pune landing page each returned 200, a self-canonical in the current live HTML, and one H1. Their current title and description lengths are reasonable; no broad metadata rewrite is recommended.
- PageSpeed Insights returned HTTP 429 and the CrUX endpoint returned HTTP 403, so this audit could not confirm mobile Core Web Vitals or a speed issue.
- Search Console provides query and country data, not a Pune-city-only organic report. Map-pack rank and Google Business Profile health were not connected. GA4 reporting was also unavailable through the connected analytics tools, so leads per organic click could not be measured.
- External keyword-volume and backlink-authority providers were not configured. No backlink-gap or exact competitor-ranking conclusion is claimed.

## Recommended order of work

1. **Fix the production redirect first.** Trace why the deployed apex host returns 307 when vercel.json requests a permanent redirect. Make the apex, protocol, and legacy .html URLs resolve to one preferred www URL using permanent redirects. Then re-check the live status and canonical on the homepage and priority service pages.
2. **Reconcile Search Console.** Remove the old sitemp.xml entry, inspect the sitemap’s indexed count in the Search Console UI, and submit/request indexing for the canonical homepage, /solar-panel-pune, /residential-solar, /commercial-solar-pune, /industrial-solar, and /services after redirects are corrected.
3. **Give each intent one owner page.** Use /solar-panel-pune for core Pune rooftop installation, /residential-solar for household-specific details, /commercial-solar-pune for commercial buyers, /industrial-solar for factories, and /areas for genuine service coverage. Make the blog and project pages support these pages with contextual internal links rather than compete with them.
4. **Strengthen local trust.** Confirm the correct business address; check that the Google Business Profile is verified and complete; align name, address, phone, categories, services, and website across major listings; request authentic customer reviews; and show actual Pune project evidence. Google says local visibility is mainly driven by relevance, distance, and prominence, including reviews and information across the web. A single profile cannot be #1 everywhere in Pune because proximity changes by searcher.
5. **Improve usefulness and proof.** Keep the current core pages focused. Replace repeated superlatives and unsupported absolute promises with specifics: who did the work, where, capacity, system configuration, approval timeline, measured result, and source/date for subsidy and tariff figures. Do not create thin pages for every neighborhood unless there is unique service and project evidence for each.
6. **Then tune snippets and measure leads.** Once Google has consolidated hosts and recrawled the pages, review page/query CTR. The overall CTR is low largely because average positions are low; the www homepage has a separate low-CTR row that should be revisited after consolidation. Confirm GA4 tracks quote forms and call/WhatsApp actions so growth is judged by qualified enquiries, not rankings alone.

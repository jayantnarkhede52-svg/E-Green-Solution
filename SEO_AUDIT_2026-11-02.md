# SEO audit — E Green Solution

**Audit date:** 2 November 2026  
**Scope:** Public site, canonical and redirect setup, sitemap/robots, representative metadata, structured data, and repository page/link coverage.  
**Status:** Baseline findings were recorded before remediation; the changes and checks below were added after that report was saved.

## Executive summary

The clearest technical SEO issue is inconsistent URL ownership. The apex domain (`egreensolution.in`) sends visitors to `www.egreensolution.in` with a temporary HTTP 307, while the destination pages declare the apex URLs as canonical. The sitemap also lists apex URLs. That sends mixed signals about which host should be indexed and can split URL-level reporting and signals while Google reconciles the versions.

This is a confirmed cleanup item, but it does not by itself explain all low visibility. The Search Console API connection returns `invalid_grant`, but a manually supplied three-month export was later reviewed. It shows 2,611 impressions and 39 clicks, with high-intent Pune searches generally averaging positions 33–60. It also shows page-level activity split between both hosts. Domain Authority 10 is a third-party estimate and does not guarantee impressions or rankings.

## Findings and priority

| Priority | Finding | Evidence and likely impact | Planned action |
| --- | --- | --- | --- |
| P1 | Apex and `www` URL signals conflict | Apex homepage currently redirects to `www` with HTTP 307. The final `www` homepage and sampled service pages declare apex canonicals. Google treats a temporary redirect as a weaker canonical signal than a permanent redirect, and the canonical currently points away from the page host. | Select `www` consistently: permanent apex-to-`www` redirect, `www` canonicals, and matching absolute URL signals. |
| P1 | Sitemap and robots sitemap declaration use the non-preferred host | The sitemap resolves through a redirect and contains 39 apex `<loc>` entries; all 39 are cross-host relative to the final `www` site. `robots.txt` also declares the apex sitemap URL. | List only final `www` canonical URLs in the sitemap and point `robots.txt` directly to the `www` sitemap. |
| P2 | Many title and description snippets are long | Repository review found 15 public-page titles longer than 60 characters and 11 descriptions longer than 160 characters. The homepage is 71/177 characters; the commercial page is 63/178. Search engines can truncate or rewrite snippets; this mainly affects how results read and potentially click-through, and is not a direct penalty or proven cause of low impressions. | Tighten wording on the affected pages while preserving useful local/service intent. Keep page-specific copy; character counts are guidance, not a ranking rule. |
| P2 | Live indexing and canonical diagnosis is unavailable | A supplied Web performance export was analyzed, but live Search Console access still returns `invalid_grant`. The export has no URL Inspection, chosen-canonical, indexing-exclusion, or sitemap-processing data. | Reconnect the correct Search Console account/property, then inspect URL Inspection, indexing, and sitemap reports. Confirm the property includes the preferred host. |
| P3 | Site authority and local visibility need measurement beyond a DA score | Moz Domain Authority 10 is a comparative third-party metric, not a Google ranking score or threshold. The audit did not have verified backlink/competitor exports or Google Business Profile data to establish an authority gap. | After Search Console access is restored, compare relevant Pune service queries/pages and audit legitimate local citations, project references, and links. ## Checks that passed

- `robots.txt` permits Googlebot crawling; no broad crawl block was found.
- The sitemap contains 39 public URLs, and sampled URLs returned HTTP 200 after redirect handling.
- All 39 sitemap URLs map to local public HTML pages. The public pages are linked from the homepage; no broken internal links or orphaned indexable pages were found in the repository review.
- No duplicate public page titles or meta descriptions were found.
- Public pages have one H1. The two pages without normal SEO metadata (`admin/login.html` and `solar-hero.html`) are intentionally `noindex` and are not in the sitemap.
- Homepage structured data validation found no required-field errors in LocalBusiness, Organization, BreadcrumbList, and FAQPage. Service/WebPage were not recognized by the validator used, which is not itself evidence of invalid markup.

## Constraints and interpretation

- Search Console: the supplied performance export covers 1 August–31 October 2026. The API authorization still fails with `invalid_grant`, so live URL Inspection, indexing, canonical selection, and sitemap status could not be checked.
- PageSpeed Insights: the mobile request was rate-limited with HTTP 429, so no PSI score or Core Web Vitals result is reported.
- Sitemap `<lastmod>` values were absent. This is an optional freshness hint and was not treated as a standalone indexing blocker; dates should only be added when they reflect real page changes.
- Snippet length counts are triage signals only. Google may generate different snippets and does not enforce a universal title/description character limit.
- A Search Console impression is recorded when a result is shown; it is separate from third-party authority scores.

## Search Console performance export

The supplied export is for Web search over 1 August–31 October 2026 (92 days), before the local canonical and metadata commit. The chart reports **2,611 impressions, 39 clicks, and 1.49% CTR**. The impression-weighted average position calculated from the daily chart rows is about **30.8**.

| Month | Impressions | Clicks | CTR |
| --- | ---: | ---: | ---: |
| August | 786 | 6 | 0.76% |
| September | 751 | 10 | 1.33% |
| October | 1,074 | 23 | 2.14% |

October was up 43% in impressions and 130% in clicks versus September. The period is trending upward; the more direct constraint is the position of valuable non-brand searches, not a recent fall in impressions.

### What is limiting visibility

- High-intent Pune terms average well below page one: `solar installation in pune` (42 impressions, position 53.21), `solar panel installation in pune` (39, position 50.18), `solar installation company in pune` (35, position 59.8), `solar panel distributor in pune` (31, position 40.39), and `solar panel dealers in pune` (27, position 33.22). Each has zero clicks in the visible query rows.
- The Pune landing page has 393 apex impressions at position 51.52 with no clicks, plus 10 `www` impressions at position 29.6. `/areas` has 133 apex impressions at position 54.59 with no clicks. Industrial solar has 42 impressions split across hosts at positions around 40. Commercial solar has only 11 split-host impressions in the export.
- The page table contains 32 apex URL rows with 2,042 impressions and 36 clicks, and 21 `www` URL rows with 967 impressions and 3 clicks. The homepage alone appears as apex (309 impressions, 20 clicks, position 24.02) and `www` (682 impressions, 3 clicks, position 7.7). This is strong evidence that the pre-fix host signals were also fragmenting Search Console page reporting. The export does not reveal Google's selected canonical; confirm it in URL Inspection after access is restored.
- The subsidy page has 221 page-level impressions across the two hosts and no clicks. The visible PM Surya Ghar/subsidy queries total 118 impressions with no clicks; most average positions are between 60 and 95. One Pune-specific query is at position 4.8, but has only five impressions. These numbers do not support making subsidy the site's main visibility strategy. Keeping a focused guide while reducing repeated mentions elsewhere remains appropriate.

### How to read the export

- The chart is property-aggregated. Page rows are URL-aggregated, so page impressions can sum above the chart total when multiple URLs from the property appear for a search. Google's documentation describes this aggregation difference.
- The visible query rows total 1,095 impressions and 3 clicks, less than chart totals, because the query table omits some anonymized and truncated rows. Use the chart for total traffic and the query table to inspect visible terms; do not treat its sum as the property's total.
- India accounts for 2,397 impressions (about 92%) and all 39 clicks. Mobile records 1,134 impressions and 21 clicks (1.85% CTR, average position 14.86); desktop records 1,476 impressions and 18 clicks (1.22% CTR, average position 43.03). Device averages can represent different query mixes and do not, by themselves, prove a mobile usability issue.

## Remediation sequence

1. Establish `https://www.egreensolution.in` as the canonical host across redirects, page canonicals, sitemap, robots, Open Graph/Twitter URLs, structured data, and language alternates.
2. Shorten the affected page titles and meta descriptions where it improves clarity without removing useful local intent.
3. Validate the edited repository and key local pages, then commit the report and fixes. The public deployment still needs the user's manual push; live redirect status cannot be verified until that deployment is published.
4. After publishing the local commit, restore Search Console authorization and inspect Google's chosen canonical, indexing status, and sitemap processing. Compare the next performance period with this pre-fix baseline.

## Remediation completed after the baseline

- Updated absolute site URLs to `https://www.egreensolution.in` across public HTML, JSON-LD, Open Graph/Twitter metadata, `llms.txt`, and `llms-full.txt`.
- Updated every canonical and all 39 sitemap entries to the `www` host; changed the robots sitemap declaration to the direct `www` sitemap URL.
- Added a Vercel host-conditional permanent redirect from the apex domain to `www` (Vercel documents `permanent: true` as HTTP 308). This routing condition cannot be exercised by the current plain local server, so confirm the status on the deployed domain after publishing.
- Shortened all 15 public-page titles over 60 characters and all 11 descriptions over 160 characters. The adjusted title and description sets have no remaining entries over those review thresholds; the thresholds are editing guidance, not Google limits.
- Aligned the homepage Open Graph title and description with its revised search metadata.

### Post-edit checks

- 39 canonicals and 39 sitemap entries use the `www` host; no apex HTTPS URL references remain in public HTML/XML/text files.
- All sitemap entries map to the site's pages (including `/blog` and `/projects`, served from their `index.html` files through clean URLs).
- JSON-LD blocks parsed successfully across the tracked HTML pages.
- The local homepage returned HTTP 200 and served the revised title and `www` canonical.
- Search Console recheck still returns `invalid_grant`; the user's manual export supplies performance data but not live indexing or canonical diagnostics. PageSpeed Insights previously returned HTTP 429.
- The Search Console export predates the local canonical/metadata commit and does not measure its effect. The source changes need the user's manual push before the live redirect can be verified.
